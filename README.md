# CreditJet за PrestaShop 8

## Генериране на инсталационен ZIP

Изисквания: Bash, PHP 8.1+, Composer и `zip`.

От директорията на модула изпълнете:

```bash
bash scripts/build-zip.sh
```

Скриптът прочита `$this->version` от `creditjet.php` и създава
`dist/CC_PrestaShop_8_JET_v.<версия>.zip`, например
`dist/CC_PrestaShop_8_JET_v.2.0.2.zip`.

Архивът съдържа папка `creditjet/` с файловете за инсталация и Composer
autoload без зависимостите за разработка. Служебните директории, IDE файловете,
stubs и самият скрипт не се включват. Подготовката се извършва във временна
директория, без промяна на локалния `vendor/`.

След успешно генериране предишните архиви `CC_PrestaShop_8_JET_v.*.zip`
в `dist/` се изтриват; при грешка предишният архив се запазва.
